BLACKRACK OVERLAY 0.10.0 - Windows x64
======================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.10.0_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
  driving so mouse input passes through.

TELEMETRY
- LMU uses its native shared memory directly.
- No external telemetry DLL or additional LMU option is required.

TRAILING + PEDAL
- The overlay has a refreshed visual style.
- The graph, current inputs and driving data can be positioned independently.
- Pedal labels in the current-input panel can be hidden.

TYRES
- Compatible used tyres keep their recorded flat-spot history when refitted,
  including while the car remains in the garage.

STANDINGS AND RELATIVE
- Visible columns follow the selected session profile.
- Virtual energy is shown in configured sessions that provide it.

DELTA AND GENERAL SETTINGS
- Delta uses a global keyboard shortcut instead of polling wheel buttons.
  To keep using a wheel button, map it to that shortcut in the wheel software
  or SimHub. Direct wheel-button assignments from earlier versions are not
  carried over automatically.
- Profile deletion confirmation is clearer and Chat timestamps are vertically
  centered.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.10.0_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
  juego antes de conducir para dejar pasar los clics.

TELEMETRÍA
- LMU usa directamente su memoria compartida nativa.
- No hace falta instalar un DLL de telemetría ni activar ninguna opción
  adicional de LMU.

TRAILING + PEDAL
- El overlay tiene un aspecto visual renovado.
- La gráfica, los inputs actuales y los datos de conducción se pueden colocar
  de forma independiente.
- Las etiquetas de los pedales se pueden ocultar en el panel de inputs.

TYRES
- Los neumáticos usados compatibles conservan sus marcas de flat spot al
  volver a montarlos, incluso mientras el coche permanece en el garaje.

STANDINGS Y RELATIVE
- Las columnas visibles respetan el perfil de sesión seleccionado.
- La energía virtual se muestra en las sesiones configuradas que la ofrecen.

DELTA Y AJUSTES GENERALES
- Delta utiliza un atajo de teclado global en lugar de consultar los botones
  del volante continuamente. Para seguir usando un botón del volante, asígnalo
  a ese atajo desde el software del volante o SimHub. Las asignaciones directas
  de versiones anteriores no se trasladan automáticamente.
- La confirmación de borrado de perfiles es más clara y las marcas de tiempo
  de Chat quedan centradas verticalmente.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar
un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
