BLACKRACK OVERLAY 0.11.0 - Windows x64
======================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.11.0_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
  driving so mouse input passes through.

TELEMETRY
- LMU uses its native shared memory directly.
- No external telemetry DLL or additional LMU option is required.

LAP TIMES
- Review saved best laps, optimal laps and best sectors by track and car.
- Search and refresh the list, or delete a record after confirmation.
- Deleted records stay deleted and do not return through older saved data.

DASHBOARD
- Brake-bias notices no longer repeat continuously while spectating AI cars.

SPECTATOR MODE
- Overlays no longer flicker against the local car while it remains in the
  garage.

PERFORMANCE AND STABILITY
- Long sessions feel smoother and remain more stable without changing the
  telemetry information shown by the overlays.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.11.0_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
  juego antes de conducir para dejar pasar los clics.

TELEMETRÍA
- LMU usa directamente su memoria compartida nativa.
- No hace falta instalar un DLL de telemetría ni activar ninguna opción
  adicional de LMU.

LAP TIMES
- Consulta los mejores tiempos, la vuelta óptima y los mejores sectores
  guardados por circuito y coche.
- Busca y actualiza la lista, o borra un registro después de confirmarlo.
- Los récords borrados permanecen eliminados y no reaparecen mediante datos
  guardados anteriormente.

DASHBOARD
- Los avisos de reparto de frenada no se repiten continuamente al seguir
  coches de IA en modo espectador.

MODO ESPECTADOR
- Los overlays ya no parpadean al mostrar el coche observado mientras el coche
  local permanece en el garaje.

RENDIMIENTO Y ESTABILIDAD
- Las sesiones largas son más fluidas y estables sin cambiar la información
  de telemetría que muestran los overlays.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar
un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
