BLACKRACK OVERLAY 0.9.0 - Windows x64
====================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.9.0_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
   driving so mouse input passes through.

TELEMETRY
- LMU uses its native shared memory directly.
- No external telemetry DLL or additional LMU option is required.

NEW OVERLAYS
- Session Info shows the selected session data in a configurable layout.
- Chat displays LMU messages, wraps long text and hides after inactivity.

PREFERENCES AND CONTROL
- Temperature and speed units can be configured globally.
- A global shortcut can show or hide all overlays.
- The player marker on Track Map can be customized.
- Standings delta can use the best lap as its reference.
- Control-panel sections can be collapsed and its settings have been
  reorganized for a clearer layout.
- The control panel includes an optional PayPal support link and an
  OpenKneeboard hint for VR browser sources.

UPDATES AND STABILITY
- Novedades can request installation of an earlier release.
- Improved LMU data cleanup after sessions and handling of lap, humidity and
  Driver Rating data.
- Added diagnostics for the lifecycle of native crashes.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.9.0_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
  juego antes de conducir para dejar pasar los clics.

TELEMETRÍA
- LMU usa directamente su memoria compartida nativa.
- No hace falta instalar un DLL de telemetría ni activar ninguna opción
  adicional de LMU.

NUEVOS OVERLAYS
- Session Info muestra los datos de sesión seleccionados en una disposición
  configurable.
- Chat muestra los mensajes de LMU, ajusta los textos largos y se oculta tras
  un periodo sin actividad.

PREFERENCIAS Y CONTROL
- Las unidades de temperatura y velocidad se pueden configurar globalmente.
- Un atajo global permite mostrar u ocultar todos los overlays.
- El marcador del jugador en Track Map se puede personalizar.
- El delta de Standings puede usar la mejor vuelta como referencia.
- Las secciones del panel de control se pueden plegar y sus ajustes están
  reorganizados para facilitar su uso.
- El panel incluye un enlace opcional de apoyo por PayPal y una sugerencia de
  OpenKneeboard para fuentes de navegador en VR.

ACTUALIZACIONES Y ESTABILIDAD
- Novedades permite solicitar la instalación de una versión anterior.
- Mejorada la limpieza de datos de LMU al terminar las sesiones y la gestión
  de datos de vueltas, humedad y Driver Rating.
- Añadidos diagnósticos para el ciclo de vida de cierres nativos.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar+un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
