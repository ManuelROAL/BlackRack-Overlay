BLACKRACK OVERLAY 0.12.0 - Windows x64
======================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.12.0_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
  driving so mouse input passes through.

TELEMETRY
- LMU uses its native shared memory directly.
- No external telemetry DLL or additional LMU option is required.

MINIMAP
- View the circuit around the player's car with nearby-car markers.
- Choose heading-up or north-up orientation and configure the visible range.
- The player's colour and icon match Track Map.

CONTROL PANEL AND SHORTCUTS
- Resize the control panel and adjust the full panel zoom from the header
  controls.
- By default, closing the panel keeps BlackRack Overlay running in the system
  tray so the overlays stay active. Change this in General > Application and
  use Quit from the tray menu to exit. It can also start there with Windows.
- Use the Global shortcuts guide to assign wheel buttons through SimHub or
  another keyboard-emulation tool.

OVERLAY SETTINGS
- Dashboard, Chat and Lift & Coast use a more consistent settings layout.
- Trailing + Pedal centres the gear and speed group without a redundant speed
  unit label.
- Overlay positions and monitor selection survive a monitor appearing late or
  being briefly unavailable.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.12.0_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
  juego antes de conducir para dejar pasar los clics.

TELEMETRÍA
- LMU usa directamente su memoria compartida nativa.
- No hace falta instalar un DLL de telemetría ni activar ninguna opción
  adicional de LMU.

MINIMAP
- Consulta el circuito alrededor del coche del jugador con marcadores de los
  coches cercanos.
- Elige orientación según el rumbo o con el norte arriba y configura el rango.
- El color y el icono del jugador coinciden con Track Map.

PANEL DE CONTROL Y ATAJOS
- Redimensiona el panel de control y ajusta el zoom de todo el panel desde los
  controles del encabezado.
- Por defecto, al cerrar el panel la aplicación sigue en la bandeja para que
  los overlays continúen activos. Cámbialo en General > Aplicación y usa Salir
  en el menú de la bandeja para cerrar la aplicación. También puede iniciarse
  allí con Windows.
- Usa la guía de Atajos globales para asignar botones del volante mediante
  SimHub u otra herramienta de emulación de teclado.

AJUSTES DE LOS OVERLAYS
- Dashboard, Chat y Lift & Coast usan un diseño de ajustes más coherente.
- Trailing + Pedal centra la marcha y la velocidad sin una unidad redundante.
- Las posiciones de los overlays y el monitor se conservan aunque un monitor
  aparezca tarde o deje de estar disponible brevemente.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar
un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
