BLACKRACK OVERLAY 0.8.1 - Windows x64
====================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate with its official
  Plugins/LMU_SharedMemoryMapPlugin64.dll.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.8.1_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
   driving so mouse input passes through.

VERSION UPDATES
- The control panel checks automatically for new versions and also supports
  on-demand checks.
- Release highlights follow the selected interface language, including when
  an update notification was already stored locally.
- The new installer can be downloaded and installed directly from the
  application.
- The installer is verified with SHA-256 before it runs.

OTHER CHANGES
- Overlay show/hide shortcuts start disabled until you assign them.
- Delete or Backspace clears an assigned overlay shortcut.
- Existing configured overlay shortcuts are preserved.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate con su archivo oficial
  Plugins/LMU_SharedMemoryMapPlugin64.dll.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.8.1_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
  juego antes de conducir para dejar pasar los clics.

ACTUALIZACIONES DE VERSIÓN
- El panel de control comprueba automáticamente si hay versiones nuevas y
  también permite buscarlas bajo demanda.
- Las novedades respetan el idioma seleccionado, incluso si el aviso ya se
  había guardado localmente.
- Puedes descargar e instalar el nuevo instalador desde la propia aplicación.
- El instalador se verifica mediante SHA-256 antes de ejecutarse.

OTROS CAMBIOS
- Los atajos globales para mostrar u ocultar overlays empiezan desactivados
  hasta que los asignes.
- Supr o Retroceso borra el atajo asignado a un overlay.
- Los atajos de overlays que ya estuvieran configurados se conservan.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar
un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
