BLACKRACK OVERLAY 0.7.7
======================
Package highlights
- Collapsible welcome guide for initial setup and overlay selection.
- Copyable support diagnostics in Integrations, with manual-copy fallback.
- English and Spanish interface and bundled overlay help.
- User-created configuration profiles; no recommended preset profiles.
- Dashboard readout selection without the former eight-field limit.

Windows x64 production installer with embedded frontend assets and WebView2
bootstrapper. Experimental simulator options are excluded. This package
targets Le Mans Ultimate.

This is a highlights list, not a complete historical changelog.
