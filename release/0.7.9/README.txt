BLACKRACK OVERLAY 0.7.9 - Windows x64
====================================
Free, configurable telemetry overlays for Le Mans Ultimate.
No SimHub, Node.js, Rust or Tauri installation is required.

REQUIREMENTS
- 64-bit Windows 10 or Windows 11.
- Le Mans Ultimate with its official
  Plugins/LMU_SharedMemoryMapPlugin64.dll.
- The Microsoft Edge WebView2 Runtime. The installer includes its bootstrapper.

INSTALLATION
1. Run BlackRack Overlay_0.7.9_x64-setup.exe.
2. Open BlackRack Overlay and select the language and monitor in General.
3. Enable the panels you want and configure them in Overlays.
4. Use Edit mode to move or resize panels, then return to Game mode before
   driving so mouse input passes through.

VERSION UPDATES
- The control panel checks automatically for new versions and also supports
  on-demand checks.
- Release highlights are shown before you update.
- The new installer can be downloaded and installed directly from the
  application.
- The installer is verified with SHA-256 before it runs.
- If an update does not complete successfully, the application reports it
  after the next start.

OTHER CHANGES
- Assign every overlay to one monitor or distribute overlays across monitors.
- Improve LMU stability when changing sessions, circuits, events or vehicles.
- Handle incomplete or incompatible LMU data more safely.
- Preserve Driver Rating results across event changes and application restarts.
- Add optional recent-lap delta columns to Standings and Relative.
- Add BEST/LAST combination, GTE class colour and hybrid battery percentage.
- Keep Dashboard width stable when speed changes from two to three digits.
- Reorder visible Timing rows with drag-and-drop or side buttons; the order is
  preserved in profiles, backups and browser sources.

COMPATIBILITY
- The current build is focused on Le Mans Ultimate.
- Experimental iRacing support has been removed.

The installer is not digitally signed, so Windows SmartScreen may warn on the
first run. Verify the installer with SHA256SUMS.txt if desired.

ESPAÑOL
-------
REQUISITOS
- Windows 10 u 11 de 64 bits.
- Le Mans Ultimate con su archivo oficial
  Plugins/LMU_SharedMemoryMapPlugin64.dll.
- Microsoft Edge WebView2 Runtime; el instalador incluye su bootstrapper.

INSTALACIÓN
1. Ejecuta BlackRack Overlay_0.7.9_x64-setup.exe.
2. Abre BlackRack Overlay y elige el idioma y el monitor en General.
3. Activa los paneles que necesites y configúralos en Overlays.
4. Usa el modo edición para moverlos o cambiar su tamaño y vuelve al modo
   juego antes de conducir para dejar pasar los clics.

ACTUALIZACIONES DE VERSIÓN
- El panel de control comprueba automáticamente si hay versiones nuevas y
  también permite buscarlas bajo demanda.
- Muestra las principales novedades antes de actualizar.
- Puedes descargar e instalar el nuevo instalador desde la propia aplicación.
- El instalador se verifica mediante SHA-256 antes de ejecutarse.
- Si una actualización no termina correctamente, la aplicación informa del
  problema al volver a iniciarse.

OTROS CAMBIOS
- Puedes asignar cada overlay a un monitor o repartirlos entre varios monitores.
- Mayor estabilidad de LMU al cambiar de sesión, circuito, evento o vehículo.
- Mejor protección cuando LMU proporciona datos incompletos o incompatibles.
- Los resultados de Driver Rating se conservan entre eventos y reinicios.
- Nueva columna opcional con el delta de las últimas vueltas en Standings y
  Relative.
- Opción para combinar BEST y LAST, color propio para GTE y porcentaje de
  batería híbrida.
- El ancho del Dashboard permanece estable al pasar de dos a tres cifras.
- Las filas visibles de Timing se pueden reordenar y el orden se conserva en
  perfiles, copias de seguridad y fuentes de navegador.

COMPATIBILIDAD
- La versión actual está centrada en Le Mans Ultimate.
- Se ha retirado el soporte experimental de iRacing.

El instalador no está firmado digitalmente y Windows SmartScreen puede mostrar
un aviso la primera vez. Si quieres, verifica el instalador con SHA256SUMS.txt.
