# BlackRack Overlay 0.8.3

## Visibilidad durante el final de sesión

- Los overlays permanecen visibles al alcanzar el tiempo de sesión o la fase
  de meta mientras el jugador siga dentro de la carrera o del servidor.
- Se siguen ocultando al volver al menú de LMU, entrar en el garaje o perder el
  vehículo activo.
