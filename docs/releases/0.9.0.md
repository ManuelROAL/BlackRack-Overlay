# BlackRack Overlay 0.9.0

## Nuevos overlays

- Añadidos los overlays **Session Info** y **Chat**.
- Session Info permite seleccionar los datos visibles y su disposición.
- Chat muestra los mensajes de LMU, ajusta el texto al espacio disponible y se
  oculta después de un periodo sin actividad.

## Preferencias y control

- Añadidas unidades configurables para temperatura y velocidad.
- Añadido un atajo global para mostrar u ocultar los overlays.
- El marcador del jugador en Track Map se puede personalizar.
- El delta de Standings puede usar la mejor vuelta como referencia.
- El panel de control incorpora secciones plegables y ajustes visuales
  reorganizados.
- Añadidos un enlace opcional de apoyo por PayPal y una sugerencia para usar
  OpenKneeboard con fuentes de navegador en VR.

## Actualizaciones y estabilidad

- Se puede solicitar la instalación de versiones anteriores desde Novedades.
- Mejorada la gestión de datos de LMU al terminar una sesión y de los datos de
  vueltas, humedad y puntuación.
- Añadidos diagnósticos para el ciclo de vida de cierres nativos.
