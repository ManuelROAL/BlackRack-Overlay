[B][COLOR=#D8FF3E]MONITORS AND CONFIGURATION[/COLOR][/B]
[LIST]
[*]Place every overlay on one monitor or assign overlays to different monitors.
[*]Each monitor with active overlays uses its own transparent host.
[*]Positions, sizes, scales and monitor assignments are preserved in profiles and backups.
[/LIST]

[B][COLOR=#D8FF3E]LMU TELEMETRY[/COLOR][/B]
[LIST]
[*]More stable behavior when changing sessions, circuits, events or vehicles.
[*]Driver Rating results are preserved across event changes and application restarts.
[*]Telemetry is more resilient when LMU provides incomplete or incompatible data.
[*]Pit-menu changes are shown when LMU provides them.
[*]Optional RaceOS or REST failures do not stop the main telemetry stream.
[/LIST]

[B][COLOR=#D8FF3E]STANDINGS, RELATIVE AND DASHBOARD[/COLOR][/B]
[LIST]
[*]Optional recent-lap delta columns are available in Standings and Relative.
[*]BEST and LAST can be combined to show the newly completed lap temporarily.
[*]GTE has its own class colour.
[*]The hybrid battery gauge also shows its charge percentage.
[*]Dashboard width stays stable when speed changes from two to three digits.
[/LIST]

[B][COLOR=#D8FF3E]TIMING[/COLOR][/B]
[LIST]
[*]Visible Timing rows can be reordered by dragging or using the side buttons.
[*]The order is preserved in profiles, configuration backups and browser sources.
[/LIST]
