# BlackRack Overlay 0.7.4

Esta versión incorpora el nuevo Historial de stints y amplía el Calculador de
combustible con objetivos y previsiones en directo para planificar mejor cada
parada.

También mejora la información de neumáticos y motor, añade comparaciones de vueltas
en Cronometraje y luces de RPM opcionales en Conducción. Delta permite cambiar su
referencia desde el volante y muestra claramente el modo seleccionado.

Se estrena una guía de overlays dentro de la aplicación y se han refinado
Clasificación, Relativo y Condiciones para ofrecer una lectura más clara. La versión
incluye además correcciones de estabilidad y numerosos retoques visuales.
