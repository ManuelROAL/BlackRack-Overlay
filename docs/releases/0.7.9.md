# BlackRack Overlay 0.7.9

## Actualizaciones de versión

- El panel de control comprueba automáticamente si hay una versión nueva y
  también permite buscar actualizaciones bajo demanda.
- Antes de actualizar, muestra las principales novedades de la nueva versión.
- Descarga e instala el nuevo instalador desde la propia aplicación.
- Verifica la integridad del instalador mediante SHA-256 antes de ejecutarlo.
- Si una actualización no termina correctamente, la aplicación informa del
  problema al volver a iniciarse.

## Monitores y configuración

- Puedes colocar todos los overlays en un monitor común o asignar cada overlay
  a un monitor diferente.
- Cada monitor que tenga overlays activos utiliza su propio host transparente.
- Las posiciones, tamaños, escalas y asignaciones de monitor se conservan en
  perfiles y copias de seguridad.

## Telemetría de Le Mans Ultimate

- Mayor estabilidad al cambiar de sesión, circuito, evento o vehículo.
- Los resultados de Driver Rating se conservan correctamente entre eventos y
  reinicios de la aplicación.
- La telemetría se protege mejor cuando LMU proporciona datos incompletos o
  incompatibles.
- Se muestran los cambios realizados en el menú de parada de boxes cuando LMU
  los proporciona.
- Los fallos opcionales de RaceOS o REST no detienen la telemetría principal.

## Standings y Relative

- Nueva columna opcional con el delta de las últimas vueltas.
- Puedes combinar las columnas BEST y LAST para mostrar temporalmente la última
  vuelta recién completada antes de volver a la mejor vuelta.
- Mejor identificación visual de las clases de vehículos, incluida GTE.

## Dashboard

- El indicador de batería híbrida muestra el porcentaje de carga.
- El ancho del Dashboard permanece estable al cambiar entre velocidades de dos
  y tres cifras.
- Se han ajustado algunos tamaños de texto para mejorar la lectura.

## Timing

- Las filas visibles de Timing se pueden reordenar mediante arrastre o botones
  laterales.
- El orden se conserva en perfiles, copias de seguridad y fuentes de navegador.

## Compatibilidad

La versión actual está centrada en Le Mans Ultimate y utiliza su plugin oficial
`LMU_SharedMemoryMapPlugin64.dll`. SimHub no es necesario.

El soporte experimental de iRacing se ha retirado de esta versión.
