# BlackRack Overlay 0.10.0

## Trailing + Pedal

- Actualizado el aspecto visual de **Trailing + Pedal**.
- Se puede elegir por separado la posición de la gráfica, los inputs actuales
  y los datos de conducción.
- Se pueden ocultar las etiquetas de los pedales en los inputs actuales.

## Tyres

- Las marcas de flat spot se conservan al cambiar a neumáticos usados
  compatibles y mientras el coche permanece en el garaje.

## Standings y Relative

- Las columnas visibles respetan el perfil de sesión seleccionado.
- La energía virtual se muestra en las sesiones configuradas que la ofrecen.

## Delta y ajustes generales

- Delta utiliza ahora un atajo de teclado global en lugar de consultar los
  botones del volante continuamente. Para seguir usando un botón del volante,
  asígnalo a ese atajo desde el software del volante o SimHub; las
  asignaciones directas anteriores no se trasladan automáticamente.
- La confirmación de borrado de perfiles indica con más claridad la acción.
- Las marcas de tiempo de Chat quedan centradas verticalmente.
