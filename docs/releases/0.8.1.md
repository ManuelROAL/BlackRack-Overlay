# BlackRack Overlay 0.8.1

## Panel de control

- Las notas de una nueva versión se muestran en el idioma seleccionado en el
  panel, tanto en español como en inglés.
- Las notas guardadas conservan sus traducciones al cambiar de idioma.

## Atajos

- Los atajos globales de mostrar u ocultar overlays empiezan desactivados para
  no reservar combinaciones de teclado inesperadas.
- Puedes asignarlos desde cada tarjeta de overlay y borrar una combinación con
  Supr o Retroceso.
